# Software -- Engineering Thesis plane


## About

This is a repository for my engineering thesis project. The project focuses on developing a RC/Autonomous plane -- for analyzing the performance of different data filtration and fusion techniques,
in the context of flight. This repo contains the code and anything software-related pertaining to the project. The hardware and mechanical aspects of the project are not included in this repository.

### Contributions

As this is a Engineering Thesis project, the work is not open for contributions. However, feel free to peruse the code and use it.
